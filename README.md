Fly Me to the Moon: a retro 1950s–60s atomic-age poster — a ringed Saturn, a red vintage car flying through space, big bold "FLY ME TO THE MOON" typography, a couple on a tiled plaza, vintage cars — designed as an editable draw.io diagram (`artwork.drawio`, built with the drawio-skill) and rendered to PNG by `render.py`. `main.py` copies the finished `art.png` to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
