Eclipse over the Sea: a bold geometric solar eclipse — a black sun ringed in gold over indigo mountains and a teal sea — designed as an editable draw.io diagram (`artwork.drawio`, built with the drawio-skill) and rendered to PNG by `render.py`. `main.py` copies the finished `art.png` to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
